# 80s Neon Wave Shaders & PostFX

Custom presentation shader extension for **Leonidas ViceCityStories (LVCS)**.

### Features:
- **Neon Bloom**: Illuminates street lights, vehicle headlights, and Vice City neon signs with an authentic retro glow.
- **ACES Filmic Tonemapping**: Modern high-dynamic-range color curve preventing blown-out highlights while maintaining deep blacks.
- **Vice Wave Color Grading**: Enriched magentas, cyans, and sunset golds.
- **Clarity & Sharpening**: Enhanced texture details for roads and architecture at HD / 4K resolutions.
