# HD Widescreen HUD & Radar

Remastered UI and HUD layout for modern widescreen displays.

### Features:
- True Hor+ widescreen positioning (HUD elements anchored cleanly to display edges).
- Remastered high-resolution mini-map radar disc.
- Crisp vector-scaled Pricedown and Gothic font typography.
- Enhanced sniper and rocket launcher targeting reticles.
