# Leonidas ViceCityStories v0.4.7 — PC HD Remake & Native Assets Release

Bienvenue dans la version **Leonidas ViceCityStories (LVCS) v0.4.7** ! Cette version fournit les artefacts officiels compilés nativement par la CI GitHub Actions (Windows, Linux, macOS) avec l'intégration des 13 mods HD Remake, le binaire natif `VCSLauncher.exe` et la réparation de l'auto-updater.

---

## 🌟 Nouveautés & Correctifs

1. **Publication native des Assets** : Fichiers `.zip`, `.AppImage` et `.dmg` compilés et attachés directement dans la section **Assets** de la release GitHub.
2. **Auto-updater sécurisé (`tools/update.py`)** : Protection de `VCSLauncher.exe` et `python/` contre toute suppression accidentelle lors des mises à jour.
3. **13 Mods HD Remake pré-activés** : Textures HD retravaillées, interface vectorielle 16:9, shaders néon 80s, physique 60-144 Hz et distance de vue 3 200 m.
